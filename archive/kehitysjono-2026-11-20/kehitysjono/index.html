GitHub Issues -tikettien tila, prioriteetti ja komponentti
Numero Tehtävä Prioriteetti Komponentti Tila Riippuvuudet

Riippuvuudet luetaan GitHubin omista issue-riippuvuuksista ja julkaistaan yhdessä tikettiaineiston kanssa. Edeltäjä estää tämän tiketin etenemisen; Estää kertoo, mitä töitä tämän tiketin valmistuminen vapauttaa. Selain ei tee tikettikohtaisia GitHub API -pyyntöjä. Komponentti tunnistetaan GitHub-labelista component:, prioriteetti labelista priority:P0–priority:P3 ja tila labelista status:. Jos tiketiltä puuttuu tila tai prioriteetti, sitä ei luokitella arvaamalla. Suljetut GitHub-issuet näkyvät Valmis-sarakkeessa.
