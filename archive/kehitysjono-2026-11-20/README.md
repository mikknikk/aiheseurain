# Kehitysjonon aiemman oman toteutuksen arkisto

Arkistoon siirrettiin 20.11.2026 käytöstä poistettu Kehitysjono-Kanbanin oma toteutus.

Sisältöön kuuluvat selainkäyttöliittymä, JSON-välimuisti, sen muodostus- ja riippuvuusautomaatiot, testit ja tekniset ohjeet.

Tämä hakemisto on passiivinen arkisto. Sen alla olevia GitHub Actions -työnkulkuja ei suoriteta, koska ne eivät sijaitse repositorion aktiivisessa `.github/workflows/`-hakemistossa.

Kehitystehtävien nykyinen käyttöliittymä on GitHub Project **Aiheseurain**. Issue-labelien ja Projectin Status/Priority-kenttien synkronointi säilyy aktiivisena erillisenä toimintona. Riippuvuudet hallitaan GitHub Issuesin natiiveilla suhteilla.

Arkistointi ei poista GitHub Issues -tehtäviä, Project-kortteja tai natiiveja riippuvuuksia.
